### **4️⃣ SCORES QN : ANALYSE HEBDOMADAIRE**

```
┌────────────────────────────────────────────────────────┐
│           CALCUL SCORE QUALITÉ (QN)                    │
└────────────────────────────────────────────────────────┘

CHAQUE SEMAINE (dimanche soir)
──────────────────────────────

1. Récupérer repas des 7 derniers jours
2. Calculer QN moyen :
   
   QN moyen = Σ(qn_repas) / nombre_repas
   
3. Attribution badge :
   
   QN ≥ 4.0  →  🟢 Excellent
   QN ≥ 3.0  →  🟠 Correct
   QN < 3.0  →  🔴 À améliorer

4. Message personnalisé :
   
   Si 🟢 → "Continue comme ça !"
   Si 🟠 → "Ajoute plus de légumes"
   Si 🔴 → "Trop d'aliments transformés"

5. Action automatique :
   
   Si 🔴 → Générer défi "7 jours QN ≥ 3"
```
